# pora-status

Публичный репозиторий-посредник между «Порой» (РФ) и наблюдателем (Амстердам): прямого трафика между ними нет (задача 29.1).

| Ветка | Кто пишет | Что |
|---|---|---|
| `pulse` | сторож «Поры», раз в минуту | `pulse.json`: только флаги и числа — system, ts, cycles, services_ok, db_ok, disk_pct (занято, %), delivery_lag_sec, alert_channel_ok |
| `checks` | workflow `checks` этого репозитория, раз в 5 минут | `checks.json`: HTTP-коды сайтов из `sites.json` |
| `observer` | наблюдатель, раз в 10 минут | `observer.json`: метка живости |

Каждая ветка — всегда один коммит (force-push): истории нет и не копится. Содержимого людей здесь нет и быть не должно.
`nastalapora` в `sites.json` проверяется, но в тревоги наблюдателя не входит, пока домена нет (задача 23).

Репозиторий публичный: здесь только флаги и числа, а минуты Actions для публичных бесплатны. Файлы `README.md`, `sites.json` и `.github/workflows/checks.yml` — копия из `locksley12/pora` (`observer/pora-status/`), их кладёт сюда наблюдатель при старте; править — там.
